# 客制化成长型 User 人设工坊

面向 SillyTavern 与 TauriTavern 的独立扩展插件，采用高辨识度左右双栏对照工作台，用于在酒馆内直接完成 User 人设构思生成、旧人设勾选保留与改写、目标字数同步、过往经历留白/补全控制、职业与伏笔防打卡调校、个人偏好积累、酒馆原生预设导出及独立自定义 API 多方案调用。

## 主要功能

### 1. 高辨识度左右双栏工作台（免上下滚动对照）
- **四层清晰视觉区分**：默认「纸墨浅白」等六套素雅实底配色均拉开底布、纯白卡片、左侧色条标题与输入框四层对比，切模式或出滚动条时锁定宽度零弹跳。
- **桌面端自动左右分栏**：左栏填要求或勾选要保留的原人设条目，右栏实时展示成稿、分段重写与框选偏好标记；保存与新建入口统一收口在常驻底栏。
- **四边 + 四角全高自然缩放**：桌面端支持 8 向隐藏热区手动拖拽缩放（最高可拉满 `100dvh`，锁死左上锚点不回弹）；提示词预览、自定义导出与自检草稿浮窗均为非阻塞可拖拽面板，不锁死底层浏览。

### 2. 三套直白内置预设 + 原人设一键勾选提取
- 内置三套直白方案（均支持修改、置顶 `★` 与一键「还原默认」）：
  - **适合抢话党**：细节饱满，包含说话口吻、思维习惯与临场反应，适合让 AI 自然代演言行；
  - **适合不抢话党**：精炼客观，只写外貌、身份与既有事实，不替玩家说话或写心理；
  - **旧人设改写与跨卡重构**：切换「改写旧人设」自动匹配，专治旧稿套话、易打卡烦人元素与换卡改关系。
- **忠于人物本色，不套反差公式**：支持直接填入「清冷感」「娇气包」「高冷寡言」「冷脸萌」「外冷内热」等神韵锚点词，顺着你的设定意图落地（表里如一或内外反差均自然成立，不强塞统一反差模板）。

### 3. 过往经历防套皮 + 职业/喜好防打卡 + 暗线稳埋伏笔 + 防照抄示例
- **过往经历塑造（防代入套皮）**：提供 `轻底色不编身世（推荐）`、`纯留白零编造（适合代入党）`、`补全成长经历（适合独立OC）` 三档，避免给代入党擅自编造违和家庭与童年旧事。
- **职业/喜好与暗线戏份控制**：默认将职业习惯（如博主、医生）与特色属性（如体弱、穿越）做在岗与日常分离；吃穿小喜好精炼收束并顺着人物性格体现外显度（不强设旁人必定全知或必定猜错）；身世与心事伏笔自带日常自然表象，不被每轮无端试探看穿；亦可选「围绕设定展开」提升相关剧情比重。
- **防示例照抄 & 防破折号增殖**：自动检测成稿中易被正文模型每轮照搬的「例如/比如」桥段与过多破折号，提供一键「+ 附上防照抄说明」与「清理破折号」；内置构思自检草稿自动剥离并支持导出酒馆隐藏草稿正则。

### 4. 人设专属避雷词包（省 Token 策略）+ 框选表达喜好
- **原创人设专属避雷包**：内置 4 类共 45 条专针对人设档案的套话避雷（悬浮赋魅、AI 简历对仗、固定打卡微动作、重复系统口号），默认折叠不占高度，并提供 `精简核心 + 我的禁写（省Token）` / `仅发我标记的禁写` / `完整发送` 三档策略。
- **拖选文字即记喜好**：在成稿框拖选任意词句自动展开快捷原因按钮（含 `不喜欢`、`表述太 AI`、`易导致剧情反复打卡` 等），个人词库采用固定高度内部滚动，加再多词条也不撑高页面。

### 5. 模型收尾自动适配、原生预设导出与独立 API
- 自动识别 Claude、Gemini、GPT、DeepSeek 及推理模型适配收尾角色，并在接口报错时透明自愈重试。
- 支持一键导出标准 **SillyTavern Chat Completion（OpenAI Settings）** 预设 JSON 与隐藏草稿正则脚本 JSON（零接口密钥残留）。
- 支持「跟随酒馆当前连接」与「自定义独立 API」多方案管理；保存人设后向 `window` 派发 `CustomEvent('ups:persona-saved')`，`detail` 包含 `{ avatarId, name, description, lorebook, isNew, characterId, chatId, mode }`。

## 安装与打开方式

1. 在 SillyTavern / TauriTavern「扩展 -> 安装扩展（Install extension）」填入仓库地址安装（开发测试期分支填 `dev`）：
   - 仓库地址：`https://github.com/Mio-Ame/user-persona-studio`
   - 分支名称：`dev`
2. 打开方式任选其一：人设管理面板「工坊」按钮、扩展魔棒菜单「User 人设工坊」、扩展设置栏按钮或 `/ups` 斜杠命令。
