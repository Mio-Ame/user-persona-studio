# 客制化成长型 User 人设工坊

面向 SillyTavern 与 TauriTavern 的独立扩展插件，用于在酒馆内直接完成 User 人设的构思直出、旧人设无损重构、模块化预设条目栈定制、个人审美成长积累、原生预设导出以及多方案自定义 API 生成。

## 主要功能

### 1. 双工作流人设引擎
- **模式 A（新建直出人设）**：输入一两句话灵感与可选必带偏好，按需注入当前角色卡公开背景，生成贴合剧场的完整 User 人设。
  - 内置两套原创流派方案：**长文代演主力方案**（1500~2800 tokens）与**手控非抢话方案**（600~1000 tokens）。
  - 可选开启**双层输出**：核心常驻设定写入 User 人设描述，延展背景自动拆分为补充世界书条目并绑定至人设。
- **模式 B（原有人设优化 / 重构）**：支持一键载入当前酒馆 User 人设或粘贴旧稿，提供三档重构能力：
  - **无损去标签与排版重整**：保留原有设定事实与核心细节，消除嵌套缩进并改写直白标签词。
  - **保核扩写丰满**：保留既有骨架，补充可支撑长文代演的行为反应与生活细节。
  - **旧人设跨卡合理化改编**：提取并锁定【人物本体核】，仅重塑【当前剧场壳】以适配新角色卡。
  - 配套原稿与优化稿对照 Diff、局部段落重生成，以及「覆盖当前人设」或「另存为新人设」。

### 2. 模块化预设条目栈与末尾消息策略
- 在「预设条目栈」页签可单条开关、上下调序、展开编辑或新增自定义规则，并支持另存、重命名与删除多套方案。
- 内置三档**末尾消息角色 / 预填充策略**，兼容不同模型与中转接口：
  - `user`：末尾保持为用户消息，兼容强制要求 `user` 收尾的模型；
  - `assistant_prefill`：末尾使用 `assistant` 预填充引导语，直出正文；
  - `prefill_plus_user`：在预填充后追加极短 `user` 触发消息。

### 3. 导出为酒馆原生预设 JSON
- 点击底部「导出预设」或条目栈中的「自定义导出」，可将当前插件内的原创方案（含自定义条目、个人审美锚点与禁写词、末尾角色策略及内置使用指引）导出为标准 **SillyTavern Chat Completion（OpenAI Settings）** 预设 JSON。
- 在酒馆「AI 响应配置 -> Chat Completion 预设」界面导入后，直接发送灵感或原稿即可在聊天窗生成同等结构的 User 人设。
- 导出预设时会自动剥离所有本地接口地址与 API Key，仅保留纯提示词与参数。

### 4. 在改稿中成长的个人审美库
- 每次手动修改初稿后，点击「归纳审美候选」即可对比差异：从初稿删去的表达自动归纳为禁写候选，定稿手动补入的句子归纳为偏爱锚点候选，勾选确认后写入本地审美库。
- 支持光标定位或选中单句一键「拉黑此句写法」或「收藏偏爱锚点」，并支持去重合并。

### 5. 自定义独立 API 与多方案管理
- 在「连接与设置」中可在「跟随酒馆当前连接」与「自定义独立 API」之间切换。
- 支持保存、切换、重命名与两步确认删除多套 OpenAI 兼容端点配置（Base URL、掩码显示的 API Key、模型拉取/手填、Temperature、Max Tokens、Top P、流式开关与连接测试）。
- 所有自定义请求通过酒馆同源后端转发，密钥仅保存于当前扩展配置，永不随预设或脱敏备份导出。

### 6. 联动事件契约（`ups:persona-saved`）
- 通过本工坊覆盖或新建保存 User 人设后，插件会向 `window` 派发 `CustomEvent('ups:persona-saved')`，`detail` 包含 `{ avatarId, name, description, lorebook, isNew, characterId, chatId, mode }`，供外部管理工具按需监听联动。

## 安装与打开方式

1. 在 SillyTavern / TauriTavern「扩展 -> 安装扩展（Install extension）」填入仓库地址安装（开发测试期分支填 `dev`）：
   - 仓库地址：`https://github.com/Mio-Ame/user-persona-studio`
   - 分支名称：`dev`
   （或直接将本插件目录放置于酒馆的 `public/scripts/extensions/third-party/user-persona-studio` 目录并刷新页面。）
2. 打开方式任选其一：
   - 点击人设管理面板工具栏中的「工坊」按钮；
   - 点击扩展菜单（魔棒图标）中的「User 人设工坊」；
   - 在扩展设置栏「客制化成长型 User 人设工坊」中点击打开；
   - 在聊天输入框执行 `/ups` 斜杠命令。

## 非阻塞悬浮窗与交互说明

- 外层透明容器不拦截酒馆主界面与聊天区点击滚动，点击窗口外部不会误关。
- 标题栏支持拖动，右下角支持无级缩放；顶栏提供 `—`（挂起为角落恢复胶囊）、`小窗`（半屏对照模式）、`×`（关闭）与 6 套不透明实底配色方案切换。
- 工具栏底部提供独立撤销（Undo）、重做（Redo）、正文复制、原生预设导出与快速保存。

## 开发与测试

在插件目录运行单元测试（当前包含 96 项基于 `node --test` 的核心引擎、宿主适配与界面交互测试）：

```bash
npm test
```

- 当前独立仓库默认位于 `dev` 分支，供桌面端与移动端真机冒烟实测确认后再合并至 `main`。
