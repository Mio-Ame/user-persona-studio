# 客制化成长型 User 人设工坊

面向 SillyTavern 与 TauriTavern 的独立扩展插件，采用左右双栏对照工作台，用于在酒馆内直接完成 User 人设构思生成、旧人设勾选保留与改写、自定义目标字数预算、个人偏好积累、酒馆原生预设导出以及独立自定义 API 多方案调用。

## 主要功能

### 1. 左右双栏工作台（免上下滚动对照）
- **桌面端自动左右分栏**：左栏填写想法或勾选要保留的原人设内容，右栏实时显示生成结果、段落重写与保存入口，全程同屏对照不翻页。
- **小窗与手机端快捷切换**：自动提供「上下同屏 / 只看要求 / 只看结果」紧凑视图切换，避免窄屏反复上下滚动。

### 2. 新建与旧人设改写双模式 + 原人设一键勾选提取
- **新建人设**：输入一两句话想法，可选「从现有人设挑几条沿用」直接勾选已有习惯/外貌细节，按需结合当前角色卡背景生成完整 User 人设。
  - 内置两套原创方案：**细致代演方案**（细节饱满，适合让 AI 自然描写言行）与**纯手控精炼方案**（只写客观外貌、身份与已知事实，不替玩家说话）。
  - 可选开启**长设定自动拆出世界书**：常驻正文写入人设描述，补充背景按关键词自动写入并绑定世界书。
- **改写旧人设**：载入当前酒馆人设后**自动拆解为可勾选条目**（支持一键「全选 / 只留外貌性格 / 清空」，无需手动复制粘贴），提供三档改写能力：
  - **整理排版并去套话**：保留全部原设定事实与细节，清理乱缩进并把直白性格标签改写为具体表现；
  - **扩写丰富细节**：保留既有骨架，按所选目标字数补充生活细节与相处分寸；
  - **换卡改背景**：原样保留勾选的外貌、性格与习惯，只根据新角色卡重写【当前背景与关系】。

### 3. 用户自选目标字数 + 字数/Token 双计数同步
- 支持直接选择 `精炼（约 600 字）`、`适中（约 1000 字）`、`标准（约 1500 字）`、`详实（约 2000 字）` 或输入任意**自定义汉字数**。
- 修改目标字数后，生成规则中的窄幅字数区间、约算 Token 预算与最大回复上限会自动同步调整；文稿区实时双显「字数 + 约算 tokens」。

### 4. 模型收尾格式全自动适配（零门槛免配置）
- 自动识别当前连接的模型与接口类型（Claude、Gemini、GPT、DeepSeek、推理模型及各类兼容反代），自动匹配合适的末尾消息角色；若上游接口对末尾消息角色有限制，还会自动转换收尾格式并透明重试，无需用户手动勾选预填充。

### 5. 导出为酒馆原生预设 JSON
- 在「生成规则」页签点击「导出到酒馆预设」，即可将当前规则方案（含目标字数、个人喜好与禁写词库及使用说明）导出为标准 **SillyTavern Chat Completion（OpenAI Settings）** 预设 JSON，在酒馆原生预设界面导入即可生成同款 User 人设（自动剥离所有本地接口地址与密钥）。

### 6. 在改稿中成长的个人偏好词库
- 手动删改初稿后，点击「记住这次改稿偏好」即可自动对比差异：删掉的表达归入禁写候选，补入的细节归入喜好候选，勾选确认后沉淀入库。
- 支持光标定位或选中单句一键「屏蔽这句写法」或「喜欢这句细节」，并支持去重整理。

### 7. 自定义独立 API 与联动事件（`ups:persona-saved`）
- 在「接口与设置」中支持切换「跟随酒馆当前连接」与「自定义独立 API」，支持保存、切换、重命名与两步确认删除多套配置方案。
- 覆盖或新建保存 User 人设后，插件会向 `window` 派发 `CustomEvent('ups:persona-saved')`，`detail` 包含 `{ avatarId, name, description, lorebook, isNew, characterId, chatId, mode }`，供快照管家等外部管理工具联动。

## 安装与打开方式

1. 在 SillyTavern / TauriTavern「扩展 -> 安装扩展（Install extension）」填入仓库地址安装（开发测试期分支填 `dev`）：
   - 仓库地址：`https://github.com/Mio-Ame/user-persona-studio`
   - 分支名称：`dev`
2. 打开方式任选其一：
   - 点击人设管理面板工具栏中的「工坊」按钮；
   - 点击扩展菜单（魔棒图标）中的「User 人设工坊」；
   - 在扩展设置栏「客制化成长型 User 人设工坊」中点击打开；
   - 在聊天输入框执行 `/ups` 斜杠命令。
