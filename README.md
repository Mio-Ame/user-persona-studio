# 客制化成长型 User 人设工坊

面向 SillyTavern 与 TauriTavern 的独立扩展插件，提供左右双栏对照工作台，用于在酒馆内直接完成 User 人设构思生成、旧人设按组勾选保留与改写、跨卡携伴客串（1～3 人原文保真与世界书同步）、多人卡子角色适配、生成板块定制、生成历史恢复、个人偏好积累、酒馆原生预设导出及独立自定义 API 多方案调用。

## 主要功能

### 1. 稳定双栏工作台与自然交互
- **六套素雅实底配色**：内置素白绯印、青岚素雅、暖砂微光、淡樱初晴、深色夜间与跟随酒馆配色，自动适配浅色与深色模式。
- **固定尺寸双栏对照**：桌面端左栏配置条件与勾选原人设条目，右栏实时编辑成稿、查看分段重写与生成历史；支持四边 + 四角 8 向隐藏热区全高（`100dvh`）手动拖拽缩放且锁死左上锚点。
- **非阻塞辅助浮窗**：另存命名、历史快照、提示词预览与自检草稿查看均采用非阻塞浮层，随时对照底层正文。

### 2. 三套内置预设、定制板块与分类常用词库
- **三套内置预设**（均支持编辑、置顶 `★` 与一键还原默认）：
  - **适合抢话党**：细节饱满，包含说话口吻、行事逻辑与情绪反应；
  - **适合不抢话党**：简练客观，只写外貌、身份与既有事实，全程不抢话；
  - **旧人设改写**：为旧人设整理排版、去掉空话或结合新角色卡重写当前背景与关系。
- **生成板块与比重定制**：支持「结构化清单版」与「自然分段版」切换，内置核心板块、关系网与亲友、身体特征、亲密设定四大分组（未勾选板块严格不生成，亲密设定默认关闭，支持添加自定义板块与调整各维度比重）。
- **七类常用设定词库**：涵盖动物系（猫系、犬系、狐系等）、气质氛围、性格特质、相处模式、人设定位、外貌特征、习惯与细节，点选即可填入灵感。

### 3. 角色卡智能适配、多人卡分流与跨卡携伴客串
- **角色真名识别与可微调**：支持按角色名搜索筛选，当角色卡名为作品标题时自动从卡内档案与世界书识别真实角色名并允许手动微调；人设正文默认省略重复主语，节省常驻上下文。
- **世界书三分法与多人大卡适配**：自动区分「人物与关系设定」「演绎修正与守则」「系统与格式」，完整保留作者防 OOC 行为守则并识别未启用分支；面对十几个角色的群像大卡支持全局名册摘要入局或聚焦勾选 1～3 位具体子角色。
- **跨卡携伴客串（1～3 位）**：支持从其他角色卡或多人卡子角色带入亲友、前任、师长等客串人物，提供三档出场频率（仅作背景底色 / 偶尔自然联络 / 同圈常驻互动）与三种承载方式（写入人设正文 / 绑定人设专属世界书 / 写入指定已有世界书），原句保真提取外貌性格与台词并按槽位原地更新，杜绝世界书重复增殖。

### 4. 生成历史保护、套话避雷与独立 API
- **最近 8 条生成历史**：成稿工具栏内置轻量历史记录，重新生成前自动保护未保存手改稿，支持一键填入编辑区与撤销还原。
- **专属避雷词包与框选记喜好**：内置 4 类人设套话避雷词包，在成稿框拖选词句即可标记喜欢或不喜欢原因。
- **原生预设导出与多通道 API**：支持一键导出标准 SillyTavern 预设 JSON 与隐藏草稿正则脚本 JSON，支持跟随酒馆连接或配置独立自定义 API 方案。
- **前端联动事件**：保存人设成功后在 `window` 派发 `ups:persona-saved` 事件（`detail` 字段：`{ avatarId, name, description, lorebook, mode, isNew, characterId, chatId }`）。

## 安装与打开方式

1. 在 SillyTavern / TauriTavern「扩展 -> 安装扩展（Install extension）」填入仓库地址安装（开发测试期分支填 `dev`）：
   - 仓库地址：`https://github.com/Mio-Ame/user-persona-studio`
   - 分支名称：`dev`
2. 打开方式任选其一：人设管理面板「工坊」按钮、扩展魔棒菜单「User 人设工坊」、角色列表「人设适配」按钮、扩展设置栏按钮或 `/ups` 斜杠命令。
