# 客制化成长型 User 人设工坊

面向 SillyTavern 与 TauriTavern 的独立扩展插件，提供左右双栏对照工作台，用于在酒馆内直接完成 User 人设构思生成、旧人设按组勾选保留与融合重塑、跨卡亲友客串、多人大卡选角适配、生成板块定制、生成历史恢复、句式级避雷归纳、酒馆原生预设联动导出及独立自定义 API 多方案管理。

## 主要功能

### 1. 符合直觉的分步工作台与稳定交互
- **清晰分步流程**：左栏按「模式与关联角色 → 第一步：填写人设想法 / 载入旧人设 → 第二步：生成板块与输出设置」顺畅排布，可选的亲友客串默认折叠；右栏专注成稿编辑、局部重写、避雷归纳与历史快照。
- **六套素雅实底配色**：内置素白绯印、青岚素雅、暖砂微光、淡樱初晴、深色夜间与跟随酒馆配色，自动适配浅色与深色模式。
- **固定尺寸双栏与 8 向手动缩放**：支持四边 + 四角隐藏热区全高（`100dvh`）手动拖拽缩放且锁定左上锚点；另存命名、历史快照、提示词预览与自检草稿查看均采用非阻塞浮层。

### 2. 三套内置预设、定制板块与胶囊分类词库
- **三套内置预设**（均支持编辑、置顶 `★`、旧配置自动平滑升级与一键还原默认）：
  - **适合抢话党**：细节饱满，包含说话口吻、行事逻辑与情绪反应；
  - **适合不抢话党**：简练平实，只写外貌、身份与既有事实，全程不抢话；
  - **旧人设改写**：支持整理排版、扩写细节，或结合新角色卡世界观重塑经历来处与关系，让人设长出真实血肉。
- **醒目的板块与比重选择**：支持「结构化清单版」与「自然分段版」切换，直观展示当前已选板块摘要；内置核心板块、关系网与亲友、身体特征、亲密设定四大分组（未勾选板块严格不生成，亲密设定默认关闭，支持添加自定义板块与调整各维度比重）。
- **胶囊切换常用词库**：涵盖动物系（猫系、犬系、狐系等）、气质氛围、性格特质、相处模式、人设定位、外貌特征、习惯与细节七大胶囊分类，切换轻便清爽，点选即可填入灵感。

### 3. 搜索一体化选角、卡中角色名适配与跨卡客串
- **搜索合一角色选择框与卡中角色名**：角色下拉框内置实时搜索；当角色卡名为作品名（如《冬日来信》）时自动识别卡中角色本名，也支持一键展开手填实际称呼；正文默认省略重复主语。
- **世界书三分法与多人大卡适配**：自动区分「人物与关系设定」「演绎修正与守则」「系统与格式」，完整保留作者防 OOC 行为守则并识别未启用分支；群像多人卡支持全局名册摘要入局或聚焦勾选 1～3 位具体子角色。
- **长设定分流与世界书蓝绿灯联动**：支持将长设定拆入世界书，并自由选择「绿灯关键词触发」「蓝灯常驻生效」或「蓝绿灯自动分流」；可选携带 1～3 位其他角色卡亲友客串，按槽位原地更新世界书条目。

### 4. 预设实时联动、句式级避雷归纳与独立 API
- **生成预设实时适配**：预设页实时解析精确字数预算（±8% 紧凑区间），并直观展示随主页同步的「成稿前草稿自检」「世界书蓝绿灯策略」与「生成板块要求」联动条目，一键导出标准 SillyTavern 预设 JSON 与隐藏草稿正则。
- **成稿句式级避雷归纳**：在成稿正文拖选词句即可标记喜欢或按「句式问题」「解释性语言过多」等原因记入不喜欢，并支持一键调用 AI 将零散忌讳提炼为通用句式/写法避雷规则。
- **独立 API 显式保存与防误触**：自定义 API 方案提供明确的「保存方案」按钮与即时反馈，手动连接测试收纳于折叠诊断区防止误触消耗额度。
- **前端联动事件**：保存人设成功后在 `window` 派发 `ups:persona-saved` 事件（`detail` 字段：`{ avatarId, name, description, lorebook, mode, isNew, characterId, chatId }`）。

## 安装与打开方式

1. 在 SillyTavern / TauriTavern「扩展 -> 安装扩展（Install extension）」填入仓库地址安装（开发测试期分支填 `dev`）：
   - 仓库地址：`https://github.com/Mio-Ame/user-persona-studio`
   - 分支名称：`dev`
2. 打开方式任选其一：人设管理面板「工坊」按钮、扩展魔棒菜单「User 人设工坊」、角色列表「人设适配」按钮、扩展设置栏按钮或 `/ups` 斜杠命令。
